# ConvoyLink — Research Questions

## Primary Research Question

Can a low-cost embedded wireless communication system provide reliable internet-independent communication between vehicles in a convoy?

## Secondary Research Questions

### 1. Communication Range
What practical communication range can be achieved between ConvoyLink nodes under different environmental conditions?

### 2. Reliability
How does packet delivery reliability change as the distance between vehicles increases?

### 3. Latency
What communication latency can be achieved for short text messages between convoy nodes?

### 4. Multi-Node Communication
How does the system perform when multiple vehicles communicate within the same convoy?

### 5. Environmental Effects
How do obstacles, terrain, vehicle movement, and other environmental conditions affect communication performance?

### 6. Power Consumption
How much power does an individual ConvoyLink node require during transmission, reception, and standby?

### 7. Scalability
How does system performance change as additional convoy nodes are introduced?

## Future Research Questions

Future versions may investigate:

- GPS-based convoy tracking
- Emergency and SOS communication
- Mesh-based communication
- Voice communication
- Dynamic routing between vehicles
- Hybrid communication architectures
- Communication performance in mountainous and remote environments

## Planned Evaluation Parameters

The prototype will be evaluated using measurable parameters including:

- Communication range
- Packet delivery rate
- Latency
- RSSI
- Number of nodes
- Power consumption
- Communication performance under movement
- Communication performance with obstacles
