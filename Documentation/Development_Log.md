ConvoyLink Development Log

Day 1 — Project Initialization

Date: 9 September 2026

Objective

Initialize the ConvoyLink project and establish the documentation and development structure.

Project Goal

ConvoyLink aims to develop an internet-independent embedded communication system for vehicle convoys. The system will initially focus on wireless text communication between multiple vehicles and will later explore GPS-based convoy coordination and voice communication.

Today's Progress

- Created the ConvoyLink GitHub repository.
- Added the project README.
- Added an open-source license.
- Established the initial project documentation structure.

Current Development Plan

Version 1 — Basic Communication

- ESP32-based nodes
- Long-range wireless communication
- OLED display
- Vehicle identification
- Two-way text messaging
- Communication without cellular internet

Version 2 — Convoy Intelligence

- GPS location sharing
- Emergency/SOS messages
- Lead vehicle and member modes
- Vehicle distance monitoring
- Improved multi-node communication

Version 3 — Advanced Communication

- Voice communication
- Higher-bandwidth communication layer
- Improved networking/mesh capabilities
- Mobile/dashboard interface
- Enclosure and field testing

Next Step

Set up the first ESP32 development environment and verify basic communication with the OLED display.
