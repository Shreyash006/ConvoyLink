# ConvoyLink — Hardware Components

## Available Hardware

The following components are currently available for prototype development.

### Main Controllers
- ESP32 30-pin ×3
- ESP32 38-pin ×1

### Displays
- 0.96-inch OLED, 4-pin ×3

### User Interface
- Push buttons ×3
- Jumper wires
- Breadboards ×2

### Power and Control
- E-816 DC-DC 12V to 3.3V/5V power module ×2
- E-390 1-channel 5V relay module ×2

### Sensors
- DHT22 temperature/humidity sensor
- BMP280 barometric pressure sensor
- HC-SR04 ultrasonic sensor
- IR sensor
- Current sensor module
- IR flame sensor
- SW420 vibration sensor
- LDR photosensitive sensor module
- MQ-2 gas sensor

### Other Components
- 3–12V DC motor
- Motor speed controller
- 4-pin LEDs ×2
- 2-pin LEDs ×20

## Components Required for ConvoyLink V1

The core V1 prototype requires:

- ESP32 ×3
- OLED display ×3
- Push buttons ×3
- Long-range wireless transceiver modules ×3
- Suitable antennas
- Connecting wires and breadboards

The long-range wireless transceiver and antenna specifications will be selected after evaluating the communication requirements and applicable requirements for operation in India.

## V1 Hardware Focus

Only the components necessary for basic communication will be used initially.

Additional sensors and actuators will not be included unless they serve a specific ConvoyLink function in a later version.
